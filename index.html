A gesture-controlled driving system using hand movement recognition, computer vision, ROS2 communication, and a simulated car environment.

Project Overview

This project demonstrates a hand movement car control system developed for 41118 AI in Robotics. The system uses a webcam-based hand gesture recognition node to classify user gestures and convert them into driving commands.

The recognised gestures are published through ROS2 topics and used to control a simulated driving environment. A web-based GUI displays the live hand tracking feed, driving status, and simulated car view to help visualise the overall system.

The project combines computer vision, machine learning, ROS2 communication, simulation, and user interface development into one integrated robotics system.

Video

Hand Gesture Recognition

The hand gesture recognition subsystem uses webcam input and landmark detection to identify user hand poses. These gestures are converted into commands such as moving forward, turning, stopping, or selecting a target block.

Driving Simulation

The driving subsystem receives gesture commands and applies them to a simulated car environment. The system allows the car to respond to recognised hand movements and move toward selected targets.

ROS2 Integration

ROS2 topics are used to connect the gesture recognition node, driving environment, and GUI. This modular structure allows each subsystem to run independently while still communicating through published messages.

GUI Dashboard

The GUI provides a visual dashboard for the project. It displays the live gesture debug feed, the driving environment view, and the current command/status information received from the ROS2 system.
